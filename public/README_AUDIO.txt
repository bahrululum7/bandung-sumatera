CARA MEMASUKKAN LAGU ANDA SENDIRI:

1. Letakkan file lagu Anda di dalam folder ini (folder /public).
2. Beri nama file: song.mp3 (misalnya: song.mp3 atau song.wav).
3. Website akan otomatis mendeteksi dan memutar lagu Anda tersebut menggantikan aransemen piano default!

Alternatif: Anda juga bisa langsung klik tombol ikon musik kecil di kontrol samping web untuk memilih file MP3 dari laptop/HP Anda.
